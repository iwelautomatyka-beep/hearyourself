Privacy Policy

Last updated: March 16, 2026

HearYourself is a low-latency live vocal monitor app. This Privacy Policy explains what data is used when you use the app and how that data is handled.

1. Data controller

Janusz Wierzchowski
Email: iwelautomatyka@gmail.com

2. What the app uses

HearYourself uses microphone access because live audio input is required for the core real-time monitor function of the app.

3. Microphone data

Microphone audio is used only so the app can provide live monitoring and visualizer feedback while the app is running. The app is intended to process this audio on the device for its core functionality.

4. Personal data

HearYourself does not require account registration for the main experience. The app does not ask users to create a profile or log in to use live monitoring features.

5. Data sharing

The app is not designed to sell personal data. If future versions introduce additional connected or cloud-based services, this policy should be updated before those features are released.

6. Permissions

The app may request access to:

  • Microphone, for live vocal monitoring and visualizer functionality.

7. Data retention

The core monitor feature is intended to work in real time. If no recording or account-based feature is added, there is generally no need to retain user audio for the main function of the app.

8. Contact

If you have questions about this Privacy Policy, contact: iwelautomatyka@gmail.com
